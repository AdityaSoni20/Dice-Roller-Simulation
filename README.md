# 🎲 Dice Roller Simulation

 📌 About the Project

The Dice Roller Simulation is a simple Python project that simulates rolling a six-sided dice. It generates a random number between 1 and 6 each time the dice is rolled.

 🎯 Objectives

* Understand the use of Python's `random` module.
* Learn how to generate random numbers.
* Practice loops and conditional statements.
* Create a simple interactive Python program.

 🛠️ Technologies Used

* **Programming Language:** Python
* **Module:** `random`
* **Platform:** Google Colab

 ⚙️ Features

* Generates a random number between 1 and 6.
* Allows the user to roll the dice multiple times.
* Asks the user whether they want to play again.
* Displays a message when the game ends.

 💻 How It Works

1. The program imports Python's `random` module.
2. It displays the Dice Roller Simulation title.
3. The user presses Enter to roll the dice.
4. A random number between 1 and 6 is generated and displayed.
5. The user can choose to roll again or exit the game.

 ▶️ How to Run

1. Open the `.ipynb` notebook in Google Colab.
2. Run the code cells in order.
3. Follow the instructions displayed by the program.
4. Press Enter to roll the dice and type `yes` to continue playing.

This project demonstrates basic Python programming concepts, including importing modules, generating random numbers, using loops, accepting user input, and applying conditional statements.
